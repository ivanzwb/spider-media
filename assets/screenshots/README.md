## 推荐拍摄方式

1. 用 Obsidian 桌面端打开任意带 Mermaid + 代码块 + 图片的笔记
2. 启用 Spider Media → 同步到平台 → 截图 webview 注入后的状态
3. 用 [ShareX](https://getsharex.com/) / 自带「Win + Shift + S」截屏，PNG 格式
4. 压缩：[squoosh.app](https://squoosh.app/) 转 mozjpeg q=80 或 oxipng

截图前关掉笔记里的个人信息 / API key / vault 路径敏感片段。
